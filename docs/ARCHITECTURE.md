# Архитектурная карта проекта SeasonForge (Project Architecture Map)

Документ описывает структуру кодовой базы, зоны ответственности директорий и правила модульности.
**Все агенты обязаны изучить этот документ перед внесением изменений.**

---

## 1. Строгие правила архитектуры и создания файлов

1. **Запрет на god-файлы**:
   * Категорически запрещено сваливать процедурную логику, тултипы, обработчики событий и тикеры в `src/app.js` или другие корневые файлы.
   * `src/app.js` — это **исключительно компактная точка входа** (~200–300 строк), которая инициализирует состояние, запускает фоновую загрузку данных и делегирует задачи специализированным контроллерам и компонентам.

2. **Создание новых файлов и модулей**:
   * **Новые файлы создавать ТОЛЬКО при реальной необходимости и СТРОГО после явного разрешения пользователя**.
   * Если логику можно гармонично разместить в существующем модуле без нарушения его единственной ответственности (SRP) — используйте существующий модуль.

3. **Dual-UI Архитектура (Изоляция Desktop и Mobile)**:
   * Десктопные компоненты: `src/desktop/components/` + `src/desktop/styles/`.
   * Мобильные компоненты: `src/mobile/components/` + `src/mobile/styles/`.
   * Единый фасад: `src/components/<Name>.js` рендерит оба контейнера (`.sf-desktop-only` и `.sf-mobile-only`) для мгновенного аппаратного CSS-переключения без скачков разметки (Zero-CLS).
   * Кросс-импорты между `desktop/` и `mobile/` **запрещены**. Общие утилиты размещаются в `src/utils/`.

## 2. Карта директорий и зоны ответственности

```text
SeasonForge/
├── data/                      # Единый источник правды (Data Layer)
│   ├── seasons.json           # База данных игр, сезонов, лиг, дат и источников
│   └── events.json            # База данных событий, турниров, стрим-дропсов и PTR
│
├── docs/                      # Документация проекта
│   ├── ARCHITECTURE.md        # Эта архитектурная карта
│   └── PROJECT_OVERVIEW.md    # Бизнес-логика, фичи и сценарии
│
├── scripts/                   # Скрипты сборки и валидации (Node.js SSG)
│   ├── build.js               # Главный генератор статических страниц (SSG)
│   ├── build-v2.js            # Сборщик единого CSS-бандла v2-bundle.css
│   └── builder/
│       ├── domMock.js         # Моки браузерного DOM для серверного рендеринга
│       └── pageValidator.js   # Автоматический тестировщик 90+ сгенерированных страниц
│
├── src/                       # Исходный код фронтенда
│   ├── app.js                 # Точка входа SPA (оркестрация и инициализация)
│   ├── game-page.js           # Контроллер страниц конкретных игр и сезонов
│   ├── config.js              # Константы приложения
│   │
│   ├── controllers/           # Специализированные контроллеры событий и логики
│   │   ├── AppController.js           # Высокоуровневые сценарии и трекинг аналитики
│   │   ├── CountdownTicker.js         # Единый 1-сек тикер таймеров обратного отсчета
│   │   ├── EventsDrawerController.js  # Боковая шторка детальной информации ивентов
│   │   ├── NavigationController.js    # Табы, свитчер режимов и навигация
│   │   └── TooltipController.js       # Тултипы таймлайна, PTR, прогнозы и позиционирование
│   │
│   ├── components/            # Единые UI-компоненты и фасады
│   │   ├── EventCard.js       # Карточки ивентов
│   │   ├── EventsTimeline.js  # Фасад таймлайна событий (десктоп + мобилка)
│   │   ├── GameCard.js        # Карточка игры (главный экран)
│   │   ├── GamesCatalog.js    # Каталог игр (мобильная вкладка)
│   │   ├── Header.js          # Шапка сайта
│   │   ├── HeroParallax.js    # Микро-параллакс шапки
│   │   ├── LangSwitcher.js    # Переключатель языков
│   │   ├── MobileNav.js       # Нижняя мобильная панель навигации
│   │   ├── Modal.js           # Базовое модальное окно
│   │   ├── ModalManager.js    # Менеджер модалок
│   │   ├── MoreMenuModal.js   # Модалка «Ещё»
│   │   ├── Navbar.js          # Левый сайдбар десктопа
│   │   ├── ProgressBar.js     # Прогресс-бар сезона
│   │   ├── StatusBadge.js     # Бэйдж статуса сезона
│   │   ├── Timeline.js        # Фасад таймлайна сезонов
│   │   └── Toast.js           # Всплывающие уведомления
│   │
│   ├── desktop/               # Изолированный десктопный UI
│   │   ├── components/        # Десктопные компоненты (EventsTimelineDesktop.js и т.д.)
│   │   └── styles/            # Десктопные стили
│   │
│   ├── mobile/                # Изолированный мобильный UI
│   │   ├── components/        # Мобильные компоненты (EventsTimelineMobile.js и т.д.)
│   │   └── styles/            # Мобильные стили
│   │
│   ├── store/                 # Глобальное реактивное состояние
│   │   └── state.js           # Реактивный стор (игры, текущий язык, активный вид)

│   ├── services/              # Сервисы сетевых запросов и данных
│   │   └── SeasonService.js   # Загрузка и кэширование данных сезонов
│   │
│   ├── utils/                 # Чистые утилиты и хелперы
│   │   ├── analytics.js       # Отправка событий в аналитику
│   │   ├── countdown.js       # Математика расчетов времени и форматирование
│   │   ├── date.js            # Форматирование дат
│   │   ├── helpers.js         # Экранирование HTML и строковые утилиты
│   │   ├── icons.js           # Библиотека векторных SVG-иконок
│   │   ├── seo.js             # Управление мета-тегами
│   │   └── status.js          # Вычисление динамических статусов (newest, ongoing, etc.)
│   │
│   ├── styles/v2/             # Модульная CSS-система
│   │   ├── tokens.css         # CSS-переменные (цвета, шрифты, отступы)
│   │   ├── base.css           # Базовые стили и сбросы
│   │   ├── layout.css         # Сетка приложения
│   │   ├── ...                # Модульные CSS-файлы компонентов
│   │   └── dist/
│   │       └── v2-bundle.css  # Скомпилированный продакшен-бандл стилей
│   │
│   └── templates/             # Шаблоны для SSG-генерации
│       ├── changelog.html
│       ├── events.html
│       ├── game.html
│       └── season.html
│
├── sw.js                      # Service Worker (PWA, Network-First для кода, кэш ассетов)
├── manifest.json              # Манифест PWA
├── index.html                 # Корневая страница приложения
└── AGENTS.md                  # Главные правила для AI-агентов
```

## 3. Чек-лист перед завершением любой задачи

1. Не раздут ли `src/app.js`? (Логика событий вынесена в `src/controllers/`).
2. Не созданы ли лишние файлы без спроса?
3. Проходит ли билд: `node scripts/build.js` (все 90 страниц валидируются без ошибок)?
4. Запрещен `git push` / `git commit` без явной команды пользователя.
